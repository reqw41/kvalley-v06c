# Точка развилки: r3-движок поверх рекомпиляции (зафиксировано 2026-07-10)

## Контекст

Два независимых трека порта King's Valley на Вектор-06Ц (оба i8080):

1. **Рекомпиляция + soft-VDP** (`tools/kv_z80_to_8080.py` → `kvalley_i8080.rom`).
   Source-level Z80→i8080 трансляция ВСЕЙ игры. Логика 1:1 (подбор, копание с
   настоящим dig-спрайтом `GFX_ProtaPico`, зарастание отверстий, ИИ мумий, двери,
   уровни — всё). Рендер = soft-VDP (перехват записей MSX VDP → теневые таблицы →
   блит). Работает: титул→геймплей, цвет (жёлтый фон + бело-красные спрайты,
   гибридный многоцвет Городецкого). **Минусы: ~13–24 Гц, фликерит.**

2. **v2/r3 нативный движок** (ручной порт логики + plane-split рендер).
   4-плановый (фон→планы 0,1; спрайты→планы 2,3), flicker-free архитектурно,
   быстрый, цветной. **Минус: логику надо портировать вручную — очень много работы**
   (каждая механика: подбор ✓ сделан, копание/dig-спрайт/зарастание/двери/уровни — нет).

## Решение

**Строим на рекомпиляции (трек 1) — вся логика уже есть и работает — и заменяем
её слой рендера на движок r3 (трек 2), чтобы получить скорость/цвет/flicker-free
без ручного порта логики.**

Причина: порт всей логики вручную (трек 2) — неподъёмный объём; рекомпиляция его
устраняет. r3 даёт качество рендера, которого не хватает soft-VDP.

Базовый билд: `kvalley_i8080.rom` (28672Б, 3 июля, стабильный деплой рекомпиляции).

## Главный технический конфликт (решить в проектировании)

Раскладки памяти двух треков **конфликтуют по планам 2,3**:
- **Рекомпиляция soft-VDP**: планы 2,3 (0xC000–0xFFFF) = ~14К ТЕНЕВЫХ таблиц
  (SAT 0xC000, спрайт-паттерны 0xC080, sat_drawn 0xC880, 3 банка паттернов 0xC900,
  tilecnt 0xE100, 3 банка цвета 0xE400, tilemode 0xFC00).
- **r3**: планы 2,3 = СПРАЙТЫ (белый/красный) + shift-LUT + sprpat.

Оба не могут владеть планами 2,3 одновременно.

## Варианты решения конфликта (проработать)

- **A. Ужать тени** до identity-теней (паттерны = собственные данные игры, без
  отдельной цвет-таблицы — цвет выводим per-tile как в r3-перекраске). Память
  освобождает 6–12К (см. SOFT_VDP_VECTOR.md §4) → хватит на r3-спрайты в планах 2,3.
- **B. Оставить тени в 2,3, апгрейдить только блиттер** soft-VDP техниками r3
  (быстрее), рендер в планы 0,1 (2 видимых плана = 4 цвета через p0,p1, как сейчас).
  Даёт скорость, НЕ даёт 4-планового цвета/flicker-free.
- **C. Гибрид**: тени перенести в main RAM где возможно, планы 2,3 отдать r3.

## Интерфейс интеграции

Рекомпилированная игра заполняет теневые таблицы (name/pattern/color/SAT/спрайт-
паттерны) — это КОНТРАКТ, который читает новый рендерер. r3 (или его техники)
рисует из них в видимые планы. Смена спрайта при копании приходит бесплатно —
игра сама грузит `GFX_ProtaPico` в спрайт-паттерн-тень.
