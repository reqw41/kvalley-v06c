# King's Valley (MSX) — точная раскраска игрового экрана

Извлечено из оригинальных исходников 2026-07-29. Байт цвета TMS9918 = `(fg<<4)|bg`,
**один байт на строку тайла**, 8 байт на тайл. R7=#E4 → backdrop dark blue: любой `bg=0`
показывает тёмно-синий.

## Кирпичи — единственный объект с программно меняющейся палитрой
`ChgStoneColor` (из `setupStage`), scheme = `((piramideActual-1)>>2)&3`, таблица `ColoresPiedra`,
формат «количество строк, цвет». Все 5 тайлов #40..#44 получают ОДИНАКОВЫЕ 8 байт.

| scheme | пирамиды | строки 0-1 | 2-3 | 4-5 | 6-7 |
|---|---|---|---|---|---|
| 0 | 1-4 | `A0` тёмно-жёлтый | `60` тёмно-красный | `A0` | `60` |
| 1 | 5-8 | `40` тёмно-синий | `70` циан | `40` | `70` |
| 2 | 9-12 | `60` тёмно-красный | `A0` тёмно-жёлтый | `60` | `A0` |
| 3 | 13-16 | `C0` тёмно-зелёный | `B0` светло-жёлтый | `C0` | **`30` светло-зелёный** (асимметрия!) |

**ДВУТОН ВНУТРИ ТАЙЛА: 4 полосы по 2 строки.** Кладка = тёмно-синий шов (bg=0) + два оттенка.

## Ворота / дверь выхода
Косяки и створки — плоский **`#30`** (светло-зелёный на тёмно-синем): тайлы #6C,#6D,#6E,#7B,#7C,#7D
и закрывающиеся #6F..#72, #7E..#81. Многотон только в кадрах «закрывается» (#5F-#62) и в
интерьере (#63 `EA EA EA EA EA A0 A0 A0`, #64, #65, #66, #67 `FE`x8 — лестница внутри).

## «Ключа» в игре НЕТ — это РЫЧАГ (palanca)
В исходнике нет ни одного `llave`. Дверь открывает рычаг:
- **#5C** `90 96 F6 F6 F6 A6 A6 A6` — рычаг внизу
- **#5D** `60 6A 6A 6A 6F 6F 6F 6F` — рычаг вверху
- **#5E** `96 90 90 90 90 90 90 90` — нижняя часть
**Мигает:** `drawBrilloGemas` каждый кадр пишет 3 байта по VDP #2E5 (тайл #5C, строки 5-7)
из `ColoresPalanca: 16, F6, A6, A6`, индекс `(timer>>1)&3`.

## Кирка
**#4C** = `90 90 90 90 60 60 60 60` — строки 0-3 светло-красный(9), строки 4-7 тёмно-красный(6).
Двутон по 4 строки.

## Нож — три разных представления
- **лежащий (тайл #4B)** = `A0 A0 A0 A0 A0 F0 F0 F0` — рукоять тёмно-жёлтая(10), лезвие белое(15).
  ЭТО И ЕСТЬ «жёлтая ручка у воткнутого ножа».
- **в полёте (тайлы #45-#4A)** — те же два цвета, граница «плывёт» по строкам (эффект вращения):
  #45 `F0F0F0A0A0A0A0A0`, #46 `F0F0F0F0F0A0A0A0`, #47 `F0F0F0F0F0F0F0A0`,
  #48 `A0A0A0F0F0F0F0F0`, #49/#4A `A0A0A0A0A0F0F0F0`
- **отскок/падение — СПРАЙТ** #F0/#F4/#F8/#FC, цвет `0F` = чисто белый, одноцветный.

## Вращающаяся дверь (не путать с воротами)
#68 `50`, #69 `F0`, #6A `50`, #6B `F0`, #54/#55 `50` (ребром), #77 `50`, #78 `F0`, #79 `50`, #7A `F0`.
`50` = светло-синий(5), `F0` = белый(15).

## Спрайты-створки входной двери — ДРУГОЙ механизм
`attribDoor` (Y, X, sprite, color): пары `#D8 цвет 1` (чёрный) + `#DC цвет 3` (светло-зелёный),
`#E0 цвет 1` + `#E4 цвет 3`. Два НАЛОЖЕННЫХ спрайта 16x16 дают двухцветность —
у спрайта один цвет на всю фигуру, в отличие от 8-байтного per-row цвета тайла.
Видны только ~2 секунды при входе/выходе, поверх героя.

## Гемы
#86 `40` синий, #87 `70` циан, #88 `D0` пурпурный, #89 `A0` тёмно-жёлтый, #8A `20` зелёный, #8B `E0` серый.
Блики: тайлы #51-#53 заливаются одним байтом из `coloresBrillo: 10, F0, A0, A0`.
