# Решение: эвакуация плоскости p2 под 2-цветные спрайты (2026-07-13)

## Цель
2-цветные спрайты (бело-красный герой как MSX) через overwrite+clear в p2+p3.
Блокер: p2 (0xC000-0xDFFF, 8К) занят тенями soft-VDP. Основная RAM почти полна
(свободно ~969Б). Нужно освободить p2.

## ГЛАВНЫЙ ПРИНЦИП (инсайт юзера)
**Убрать VDP-ЭМУЛЯЦИЮ — всё рисовать прямыми нативными вызовами.** soft-VDP
(перехват записей игры в MSX VDP → тени → блит) — эмуляционный слой И источник
теней. Заменяя каждую VDP-точку игры на прямой нативный вызов (vec_nat_*), убираем
и слой, и тени → p2 освобождается БЕЗ сжатия кода.

Уже сделано этим путём: drawRoom→vec_nat_room, updateSprites→vec_nat_sprites,
native_print_a. Осталось: HUD, окончательная эвакуация теней.

## КЛЮЧЕВОЙ КУСОК: HUD прямым рендером (инсайт юзера)
HUD = 1 строка. Метки (SCORE/HI/REST, ©KONAMI PYRAMID-05) статичны, цифры (счёт/
hi/жизни) — 3 значения. Вывод через СУЩЕСТВУЮЩУЮ текст-процедуру (renderHUD/
renderScore/native_print_a), но НАПРЯМУЮ в framebuffer, минуя name-таблицу.
→ HUD не создаёт резидентную зависимость от name_shadow/dirty/HUD-глифов.
Это РАЗБЛОКИРУЕТ «неустранимый минимум», который субагент шаг2 считал резидентным.

## Карта теней p2 (8К) и статус
| Тень | Размер | Решение |
|---|---|---|
| col_shadow гем-мерцание | — | ✅ убрано (шаг 1, коммит 22de1df) |
| sat_shadow + sat_drawn | 256Б | ✅ убрано мёртвым (шаг 2, коммит be5d9dd) |
| pat_shadow | 2К | транзиент/прямой рендер фона |
| col_shadow | 2К | транзиент/прямой рендер фона |
| name_shadow | 768Б | транзиент ПОСЛЕ HUD-прямого (иначе резидент для HUD) |
| dirty + tiledirty | 256Б | убрать после HUD-прямого (клиент был HUD-drain) |
| spr_shadow | 2К | компактный ремап (реальный след ~1.2-1.3К) — субагент |

## Замеры (подтверждённые)
- Объём кода: 26.2К (рекомпиляция Z80→i8080 ×1.60 + нативный рендер 1.9К).
  MSX оригинал 16К, БК-0010 16К (ручной нативный PDP-11), Городецкий Z80 14.6К.
- **Сжатие кода НЕ решает** (спайк): код исполняется in-place, распаковка
  возвращает те же 26К → выигрыш ~0К. i8080 ZX0-декодер ЕСТЬ (92Б,
  docs/reference/.../dzx0-fwd.asm) — но только для overlay-ассетов (~2-4К).
- **Частичная транзиентность фон-тайлов НЕ работает** (анализ): транзиентные и
  резидентные тайлы разбросаны в одной 256-слот таблице, непрерывный блок не
  освободить (<0.5К дырами). Хвост 0x8c-0xFF (1.8К) занят тайлсетом ТИТУЛА —
  освобождаем если титул переунпаковывать в младшие слоты (лабиринт тогда не показан).

## Разделение по объёму (важно, связь с БК)
1. **VDP-эмуляция** (soft-VDP ~2К рантайм + 8К тени) → устраняется прямыми
   вызовами → освобождает p2. Это путь к 2-цветным спрайтам.
2. **Логика игры** (26К ×1.60) → НЕ уменьшается заменой VDP. БК-паритет (16К) =
   ОТДЕЛЬНАЯ деинфляция рекомпиляции (IX/IY, exx, block-ops → плотный i8080, рычаг B).

## РЕЗЕРВ: трюк Exolon (скрытый план)
Если прямой рендер не освободит достаточно: уйти на 3 плана с комбинаторным
8-цветом → план0 как скрытая RAM 8К (pal[i]==pal[i+8]) под тени, БЕЗ сжатия.
Цена: color-clash (фон+спрайты делят 3-плановый бюджет), но оба цвета сохранены.

## ПЛАН реализации (свежая сессия)
1. HUD → прямой framebuffer через существующую текст-процедуру (glue-замена
   renderHUD/renderScore). Гейт: логика + honest (счёт/жизни верны). → освобождает
   name/dirty резидентность.
2. dirty/tiledirty убрать (клиент HUD ушёл). → +256Б.
3. Фон прямым рендером без pat/col-теней ИЛИ хвост-титул эвакуация (1.8К).
4. spr_shadow компактный ремап в основную RAM (субагент оценивает).
5. Собрать освобождённое → p2 под 2-цветный overwrite+clear спрайт-блит (готов в r3).
Гейты каждого шага: z80_logic_gate (protaAttrib тик 824) + honest-рендер.

## ОБНОВЛЕНИЕ (по ходу шагов)
### Сделано
- Шаг 1: гем-мерцание убрано (22de1df).
- Шаг 2: sat_shadow+sat_drawn мёртвые убраны 256Б (be5d9dd).
- Шаг 3: tiledirty мёртвый убран 96Б (94b383a).

### Корректировка про dirty/name (субагент dirty)
vec_dirty (cell-очередь) НЕЛЬЗЯ убрать — нужна ШИРЕ HUD: питается vw_name для
ВСЕЙ динамики лабиринта в комнате (drawTile: копание ям/нож/кирка/ловушки +
drawCortinilla шторка перехода). name_shadow тоже резидентен для этого.
=> HUD-прямой рендер убирает лишь HUD-долю; name/dirty остаются для динамики лабиринта.
Чтобы освободить name/dirty ПОЛНОСТЬЮ, надо заменить прямыми нативными вызовами
ТАКЖЕ drawTile (копание/нож/кирка) и drawCortinilla (шторка) — расширение принципа.

### КРУПНЫЙ РЫЧАГ: неигровые экраны отдельным кодом (инсайт юзера)
Титул и экран МЕЖДУ УРОВНЯМИ — неигровые, вне игрового цикла. Их тайлсет занимает
хвост тайл-таблицы 0x8c-0xFF (1.8К pat+col), в геймплее МЁРТВ (лабиринт=0x40-0x8b).
Рисовать эти экраны ОТДЕЛЬНЫМ нативным кодом (не через soft-VDP игрового цикла) =>
их графика не нужна резидентно в геймплее => хвост p2 (1.8К) свободен во время игры.
Самый крупный непрерывный освобождаемый кусок. Приоритетный шаг.

### Пересмотр приоритетов эвакуации (по величине выигрыша)
1. Неигровые экраны (титул/меж-уровень) отдельным кодом => хвост p2 ~1.8К [КРУПНО]
2. spr_shadow компактный ремап ~0.7-0.8К (след ~1.2-1.3К vs 2К) [субагент]
3. drawTile/drawCortinilla → прямые нативные => освобождает name/dirty (~1К) [расширение]
4. HUD-прямой => убирает HUD-долю name/dirty
5. Фон pat/col: частичная транзиентность НЕ работает (разброс) — только через
   полный прямой рендер фона без теней
Резерв: Exolon скрытый план (8К под тени без сжатия, цена — color-clash).
