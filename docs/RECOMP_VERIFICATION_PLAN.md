# Программа «вылизать технологию рекомпиляции» (план, 2026-07-03)

Цель: не ловить баги по одному, а сделать транслятор ДОКАЗУЕМО корректным
переиспользуемым инструментом для всех будущих портов (Z80→i8080).

## 1. ЛОКСТЕП-ВЕРИФИКАТОР (ключевой инструмент)

Идея: оба таргета из ОДНОГО исходника детерминированы по тикам (демо, без
ввода). Состояние ИГРЫ после тика K обязано совпадать бит-в-бит.

- MAP-раскладка игровых переменных ИДЕНТИЧНА в обоих таргетах (одни имена,
  одни смещения от GameStatus; наши vec_*-ячейки добавляются В КОНЕЦ) —
  сравнивать префикс MAP (игровые переменные до первой vec_*).
- Headless-Vector уже есть (node + vector06js). Headless-MSX: Z80-ядро из
  vector06js/z80_adapter.js + ~50 строк обвязки (порты 98/99 -> VRAM-массив,
  ISR по кадру на 0x38 — MSX-glue самодостаточен, BIOS не нужен).
- Локстеп: тик-в-тик, diff MAP-префикса; дивергенция = тик+переменная.
- Уточнение внутри тика: сравнение ПОТОКА УПРАВЛЕНИЯ по меткам (.sym обоих
  таргетов: последовательность посещённых меток должна совпадать; PC/офсеты
  различаются легально). Первая разошедшаяся метка = рутина с багом; дальше
  регистры на её входе.
- Бонус: VRAM-теневая сверка (наша тень vs MSX VRAM) по тем же тикам ловит
  баги VDP-слоя отдельно от логики.

## 2. ЮНИТ-ТЕСТЫ МНЕМОНИК

Мини-программы на «опасные» инструкции (по одной группе): adc/sbc hl (Z/C/S),
bit/set/res (флаги+сохранение A!), ix/iy все формы (контракты регистров),
exx/ex af, djnz на границах, ldir-краевые, daa, rld/rrd.
Каждая: выполнить на Z80-ядре и на трансляте, сравнить регистры+флаги+память.
Прогонять при каждом изменении транслятора.

## 3. АУДИТ КОНТРАКТОВ (по журнальному опыту — 4 инцидента класса)

Каждый макрос транслятора и каждая glue-замена сопровождается явным
комментарием контракта: какие регистры/флаги оригинал сохраняет, что читает
следующий код. Чек-лист в шапке транслятора.

## Открытые баги, которые верификатор должен поймать
- «01»-тайлы (0x10/0x11) в r0c0-1/r2c0-1 после тура на экран-2 (см. JOURNAL
  за 2026-07-03: репро, отсеянные цепочки, подозреваемые: coordVRAM_DE с
  X>=256, ix/exx в getDoors/cortinilla). Подтверждено юзером: в MSX-версии и
  у Городецкого «01» НЕТ — это глюк трансляции.
- Порча стены слева на P02 при уходе мумии на экран-2.
