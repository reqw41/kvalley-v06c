# Канонический исходник King's Valley 8C (Вектор-06Ц)

`kvalley_8c.asm` — ЕДИНСТВЕННЫЙ исходник игры с точки заморозки транслятора
(тег `asm-freeze`, 2026-07-28, эквивалент коммита c49aaa0, ROM md5
9a4353889e07d46bcb4a74598e977a47). Прямые правки делаются ЗДЕСЬ.

Транслятор `tools/kv_z80_to_8080.py` + `msx/kvalley_src.asm` — ЗАМОРОЖЕНЫ,
из конвейера исключены (аварийная перегенерация: KV_8COLOR=1 + tools от тега).

Сборка: `./build.sh` (sjasm → build/ → деплой kv8c.rom + devector/).
Пока файл монолитен (17К строк) действует ГЕЙТ ЗАМОРОЗКИ: ROM байт-в-байт
(build/freeze.md5). План разрезки на модули: game/*.asm + v06c/*.asm
(layout/isr/sprites/saveunder/blit/palette) — см. память проекта.
