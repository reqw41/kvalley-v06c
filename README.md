# King's Valley 8C — Вектор-06Ц

Порт King's Valley (Konami, MSX) на Вектор-06Ц, 8-цветный движок.

## Старт и читы

Игра сразу показывает титул King's Valley; отдельный экран Konami удалён.
Обычный старт пробелом оставляет отладочные клавиши выключенными.
**F1+F3 на титуле** запускает партию с читами:

- **N** — следующая пирамида; **H** — на пять пирамид вперёд (максимум 15).
- **G** — включить/выключить бессмертие; **D** — погибнуть даже при бессмертии.
- **E** — перейти к финалу игры.

Удержание клавиши не повторяет действие: для следующего перехода отпустите и нажмите снова.
Обычный ROM и Splash-версия используют один порядок: **F1+F3 на титуле**, затем читы в игре.
На пятисекундной обложке Splash читовых клавиш нет.

## Структура (действующая)

- `src/kvalley_8c.asm` — **единственный канонический исходник** (каркас include).
  Код уже на i8080 (в Z80-мнемониках, подмножество 1:1); никакой трансляции при
  сборке нет. Оригинальный Z80/MSX-код и транслятор — только история (см. legacy/).
  - `src/game/` — замороженная игровая логика + переменные (equ-карта памяти)
  - `src/v06c/` — векторный рантайм (бут, ISR, блиттеры, спрайты, save-under...)
  - `src/res/` — ресурсы (графика RLE, музыка)
- `build.sh` — каноническая сборка: sjasm → паддинг 28К → гейт заморозки (md5) →
  гейт паритета Devector (тот же исходник, байт-в-байт) → деплой kv8c.rom + devector/
- `kvalley.project.json` — проект Devector (VS Code): Compile/Run Project прямо из
  редактора, ROM в devector/kvalley.rom (без паддинга — для отладки не важно)
- `tools/bin/sjasm` — ассемблер CLI-конвейера
- `tools/verify/` — гейты/проверки (devector_gate.js — в build.sh)
- `tools/kv_z80_to_8080.py` — ЗАМОРОЖЕННЫЙ транслятор (аварийная перегенерация:
  тег asm-freeze; в сборке НЕ участвует)
- `tools/sjasm_to_devector.py` — одноразовый конвертер синтаксиса (документация правил)
- `docs/` — спеки

## Что не входит в публичную копию

Это открытая копия рабочей ветки `3p` одним коммитом. В неё не вошли: ROM-файлы (оригинальный
картридж MSX, сборки порта, игры других авторов), папка `legacy/` (MSX-исходники, рекомпилятор,
трассы, исходники версии для БК), `docs/reference/external-engines/` (чужой код для сравнения),
`build/` и `outputs/` (сборки и рабочие отчёты). Ссылки на них в комментариях и документах
остались от рабочей истории. Сборка (`build.sh`) от этих папок не зависит.

King's Valley — © Konami, 1985. Графика, музыка и логика игры принадлежат правообладателю.

## Правила

- Новый код — только в общем подмножестве sjasm+Devector (0x-литералы, .if/.endif
  без ELSE, .include/.align/.ds; без h-суффиксов, #hex, MAP, jr/djnz).
- Один флаг/правка = один деплой; перед деплоем зелёные гейты.
- Деплой всегда в фиксированное имя kv8c.rom.

## Содержимое файлов (в порядке include каркаса)

`src/kvalley_8c.asm` (17 строк) — каркас: 12 `.include` в порядке секций исходного
монолита = порядок кода в ROM. Менять порядок нельзя (адреса запечены).

### game/ — замороженная игровая логика

- **`game/kvalley_game.asm`** (12.8К строк, ЗАМОРОЖЕНА) — вся логика оригинала,
  переведённая Z80→i8080: `org 0x100` + `jp vec_init`; `tickMain` — игровой тик
  (зовётся из ISR через H_TIMI); герой/мумии/двери/предметы/лестницы; экраны
  (меню, титул, карта пирамид, скролл, финал); музыкальный драйвер (обработка
  MUS_*-треков, джинглы по событиям); демо-режим. Комментарии — испанский
  дизасм оригинала + наши правки с пометками. Ресурсы res/ включены по месту
  (данные лежат на исходных ROM-адресах — физически не двигать).
- **`game/kvalley_vars.asm`** (365 строк) — карта памяти игры: бывший MAP-блок,
  развёрнутый в equ-цепочку с запечёнными адресами от 0x6C00 (GameStatus,
  sprAttrib/enemyAttrib, каналы музыки, счёт/жизни...) + ячейки эмуляции
  Z80-регистров (z80_ix/iy/alt) и вектор-специфичные equ.

### v06c/ — векторный рантайм

- **`vec_boot.asm`** (211) — equ-карта плана 3 (save-under слоты @0xE000,
  vec_spr_buf/mir, pat-кэши maze/font, скретчи 0xFD80+, флаги vfl_*) и
  `vec_init`: очистка всех 4 планов, установка RST7→vec_isr, палитра, режим
  портов клавиатуры, прайм vec_tilemode (FF) и vec_nsp_prev (скрыты), глушение
  ВИ53 → `jp startCode`.
- **`vec_palette.asm`** (105) — `vec_setpal` (бут: PPI 0x88 + палитра),
  `vec_setpal_menu` (карта/пергамент), `vec_setpal_a` (игровая), общий вывод
  16 регистров в VBlank; таблицы `vec_pal` (8-цветная: пары idx схлопывают p3),
  `vec_pal_menu`. Комментарии = история слоёв раскладки,
  финальная — раскладка пользователя 2026-07-21.
- **`vec_isr.asm`** (537) — `vec_isr`: обработчик RST7, кап вложенности 3,
  сохранение регистров и z80-скретчей; на глубине 1: палитра → brillo → скан
  клавиш → flushvi → H_TIMI (игровой тик); глубина ≥2 — только звук. `WRTPSG`
  (перехват PSG → тень vec_ayregs), `vec_flushvi`+`vec_ay2vi` (AY→ВИ53, ×13.5,
  дедуп), джойстик (порт Вектора → образ MSX), `WRTVDP`-заглушка, приём
  VDP/VRAM-записей: фолд банков, тени паттернов/цвета, RLE-заливки.
- **`vec_blit.asm`** (1464) — фоновый рендер: `vec_su_fixup` (обновление
  save-under слотов при фон-блите + sticky-dirty), `vec_blit_tile`/`vbt8_ent`
  (8C: p0=шейп через vbt_core, p1/p2 по white-флагу и vec_col8; `vbt8_brick`
  2-тон кирпичи; блеск 0x51-0x53), `vbt_core` (режимы blank/pat/inv/solid/mix
  из кэша vec_tilemode), `vbt_row` — POP-блиттер фона (SP=паттерн), `vbt_mix`
  (построчно-смешанные тайлы), `vec_col_store`/`vec_mode_full` (инкрементальный
  пересчёт режимов), `vec_td_range` (инвалидация), `vec_revtab` (LUT реверса,
  .align 256), `vec_text_blit`/`vec_blit_rect` (единый текстовый шов; двери),
  `vec_brillo_pal` (VBlank-анимации палитры: аура idx4, схема idx8, пульс
  карты), `vec_nat_room` (отрисовка комнаты из MapaRAM), звёзды бонус-экрана.
- **`vec_sprites.asm`** (441) — `vec_nat_sprites`: фаза F (детект изменений
  cur/prev + sticky + форс по GameStatus) → фаза P (распространение по
  пересечениям, |dY|<16 |dX|<24) → Pass-R (restore слотов 20→0) → forward
  (save+draw 0→20); выбор плоскостей: герой dual (кожа p1 + одежда p2), мумии
  по цвет-нибблу tiposMomia (золото/серый), ворота masked; `vec_spr_flush`
  (чистый подбор предмета: restore всех слотов + prev=скрыт).
- **`vec_saveunder.asm`** (481) — слоты save-under: `vec_su_ptr` (страница
  0xE0+idx), `vec_su_restore` (слот→fb, до 3 плоскостей), `vec_su_save`
  (fb→слот: клип краёв, dual/masked заголовки hi0b/hi0c); `vec_nsx` (подготовка
  спрайта: зеркало на лету для pat 0x60-0x93, клип правой половины по X),
  `vec_nsx_col` (столбец: ротация X&7 → rot-петли); `RDVDP`/`SNSMAT`-заглушки,
  `vec_scan_keys` (реальная клавиатура Вектора → образ MSX-ряда 8).
- **`vec_rotblit.asm`** (402) — jump-table `rot_tab` + 8 петель `rot0..rot7`
  (специализация по сдвигу X&7, константные маски, OR-draw) + `rotm_loop`
  (универсальная masked ANDN для непрозрачных створок ворот).
- **`vec_mirror.asm`** (51) — `vec_spr_mkmir`: построение зеркало-кэша
  hero/momia (обмен половин + бит-реверс по LUT), раз после загрузки анимаций.
- **`vec_ldir.asm`** (38) — `vec_ldir_fwd`/`bwd`: общие stack-safe циклы
  копирования (возврат через il_tmp2, не через стек).

### res/ — ресурсы (включаются из game по месту, RLE-формат:
count&0x7F, bit7=литералы/заливка, 0x80=новый адрес, 0=конец)

- **`res_ui_gfx.asm`** (302) — шрифт GFX_Font, тексты HUD/меню (REST, SCORE,
  HI, KONAMI 1985, PUSH SPACE KEY, PLAY START, GAME OVER,
  (C)KONAMI PYRAMID-), логотип King's Valley +
  пирамида меню (паттерны/атрибуты/name table), DemoKeyData + соседний код
  загрузки/подъёма логотипа.
- **`res_sprites_tiles.asm`** (164) — спрайты героя (базовый/с ножом/с киркой),
  мумии (MOMIA), вторичные (вспышка/стена/взрыв/нож), игровые тайлы (InGame),
  гемы (GEMA), таблицы цветов COLOR_*.
- **`res_music.asm`** (115) — треки MUS_* (меню, геймплей, смерть, клир,
  пергамент, вход/выход пирамиды, финал) + катакана-идентификатор оригинала.
- **`res_maps.asm`** — ГЕНЕРИРУЕТСЯ из `res/maps/pyramids.txt` (tools/maps_compile.py,
  зовётся build.sh; руками не править). Содержит пул полуэкранов halfMap1-4
  (14 шт по 44Б) + блоки MapStage1-15. Данные строго read-only (вотч 18К кадров).
- **`res/maps/pyramids.txt`** — РЕДАКТИРУЕМЫЙ исходник карт: полуэкраны ASCII-артом
  ('#'=кирпич, 22x16), на пирамиду — список полуэкранов (группы A-D = позиции слева направо, комната =
  2 полуэкрана, последний обязан быть из D — терминатор движка), 4 двери (y,x,куда,направление),
  мумии, гемы, ножи, кирки, вращающиеся двери, СТЕНЫ-ЛОВУШКИ, лестницы. После правки —
  ./build.sh (гейт заморозки при этом закономерно покраснеет: обнови build/freeze.md5
  осознанно). ВНИМАНИЕ: сборка из Devector GUI генератор НЕ запускает — после правки
  текста сначала ./build.sh (он перегенерирует res_maps.asm), потом можно собирать в GUI.
  Декомпилятор (восстановление текста из ROM): tools/maps_decompile.py.
